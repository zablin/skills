# 三问因果链

## 三问不是清单

稀缺性回答机会为什么出现，价值传导回答机会如何到达目标公司，价值捕获回答公司能持续留下多少。每个关键箭头都要回答“为什么”和“凭什么”，取证后返回修正，不能用三个独立答案代替因果链。

## 上问：稀缺性

围绕需求、有效供给、真正瓶颈和持续性检验：

- **需求：** 谁的真实任务或使用量增加，是否有支付能力和采购必要性？区分终端消耗、提前备货、重复下单及补贴刺激。
- **有效供给：** 在所需规格、质量、认证、地点和期限内，真正可交付多少？比较现有供给、可替代供给及新增供给，不能把扩产公告、理论性能或账面产能直接视为可售能力。
- **瓶颈：** 约束位于资源、技术、工程、客户认证、生态迁移还是交付环节？需求是否必须经过它，是否能降规格、改架构、自研或绕开？技术难度高不自动构成商业稀缺。
- **持续性：** 稀缺来自短期事件、周期、资源限制、制度安排还是结构性能力？比较需求变化与有效供给响应速度，说明稀缺窗口及其结束条件，不套用固定年限。
- **公司占位：** 目标公司是否拥有相应能力、客户认可和可交付份额？瓶颈业务占公司多少、能否形成实质贡献？不能由行业缺口推定所有参与公司受益。

扩产通常还要经过资金、建设、设备、投产、良率爬坡、认证与客户验收；按对象检查实际约束，不机械穷举。价格、交期与客户行为可辅助检验稀缺，但单一指标还可能受产品结构、合同与库存影响。

本问应辨清：什么在什么条件下稀缺，公司是否占据该瓶颈，以及何种供给或替代变化会削弱它。

## 中问：价值传导

检验路径：**需求变化 → 客户采购 → 订单 → 交付/验收 → 量、价、结构 → 收入**。不同业务可调整节点，但不能跳过决定收入兑现的机制。

- 客户为什么愿意付费，预算由谁控制，产品解决了什么问题？产业相关性不能替代真实采购。
- 订单是否具有约束力，有无取消条件、合同上限或重复预订？供应关系还需核对规格匹配、采购份额、实际交付及收入重要性。
- 产能、原料、交付、验收和收入确认是否匹配？订单存量不等于当期收入。
- 收入由销量/付费客户与用量、实现价格、产品结构及汇率中的哪些因素驱动？行业增长、公司份额增长与并表变化分开解释。
- 谁定价、谁承担原料涨价、资本开支及履约风险？长协、调价条款、成本转嫁、付款条件如何分配利润池？产品经过某环节不代表该环节有议价权。

关注传导调节因素：重复下单与补库存可能放大波动，长协与验收周期可能延迟兑现，库存和多元客户可能缓冲冲击；其方向与程度取决于具体业务，不能预设永远有利。

每个重要箭头说明机制、支持证据、滞后和断点。成本与资金压力可在此定位，最终能否留住利润和现金回到下问验证。不能用“A供应B、B供应C”证明“A已受益于C”。

## 下问：价值捕获

先看商业模式，再验证收入如何形成毛利与经营利润、如何转为现金，以及维持业务需要多少再投资。这是分析顺序，不是把利润与现金写成串行会计恒等式。

- **毛利与费用：** 分开营业成本和期间费用，解释售价、产品结构、良率、利用率、研发与交付成本如何影响利润。增收不增利需要解释，不能仅凭规模认定利润改善。
- **现金转换：** 结合应收、库存、预付款、应付和收款节奏解释经营现金流。利润不等于回款，预收款带来的暂时现金改善也不自动代表持续盈利。
- **必要再投资：** 关注设备更新、研发及维持交付能力的投入；区分维持与增长开支，无法拆分则保留不确定性。经营现金流扣除资本开支的结果不等于可分红利润。
- **单位经济：** 有清晰最小经营单元时，验证单位收入能否覆盖相应成本及必要投入。按量业务可拆为“付费客户数 × 户均付费使用量 × 平均实现单价”，再检查单位成本；制造业按单件或订单拆解，不能硬套客户公式。口径一致且避免重复计费，规模增长不能替代单位经济验证。
- **持续机制：** 将优势连接到客户价值、财务结果、竞争复制难度和失效条件。定价权看实现价格与毛利，切换成本看留存与复购，规模优势看单位成本，稀缺能力看有效订单、份额或资本回报；未兑现时区分合理滞后、尚未商业化与优势不存在。

护城河是动态机制，不是“技术领先、品牌强、生态好”等形容词。选择最强竞争解释：对手正面复制、客户自研或多供应商、新技术、标准化、开源或不同收费方式，是否会绕开公司、重新分配利润池？只展开与对象有关的路径。

治理、融资与资本配置仅在影响价值留存时补查，例如低回报扩张、再融资依赖、持续稀释或关联交易，不扩展为独立研究体系。

## 反转与最薄弱环节

捕获阶段检查公司商业逻辑怎样失效；最终回看整条链，找出最可能改变结论的关键假设。区分“证据最弱”与“机制已出现恶化”，不能把未知当作负面事实。

将关键假设对应到可推翻条件、可观察指标或事件、观察来源及适用频率。阈值须有依据，否则给变化方向与待确认标准，不编造通用阈值。信号出现后说明应重查、下调还是推翻哪一段判断，不自动生成交易动作。

例如交期缩短且实现价格下降可能削弱稀缺假设，应排查结构和季节性；收入增加而应收、库存持续占用现金可能削弱捕获判断，应排查扩张与回款滞后。示例不是对所有公司的固定判定标准。

## 按商业模式适配

| 业务 | 按需优先检查 |
| --- | --- |
| 硬件/制造 | 产品规格、认证、有效产能、良率、制造效率、售价、交付与周转 |
| IDC/算力租赁等重资产服务 | 可售容量、利用率、单柜/单位收入、电力、折旧、融资、更新开支与回收期；能效不等于盈利 |
| 平台/API | 模型、工程、生态与资源的组合能力，付费客户、有效用量、实现单价、稳定性、推理与交付成本；能力或调用量不等于收入 |
| 订阅 | 付费转化、留存、续费、扩张、服务与获客成本、回收期；ARR不等于当期收入或现金 |
| 项目/私有化交付 | 合同范围、验收、定制人力、可复制性、回款与后续维护责任 |

这些是同一三问链的业务适配，不另设平级框架，不要求所有指标全部采集。
