# 数据来源与溯源

目标是让关键事实能回查、关键数字能复算，区分披露、解释与预测。核验重点是决定三问结论的证据，不给所有背景信息施加同等记录负担。本文件负责证据可信度，商业判断返回三问。

## 1. 分开来源等级与内容性质

来源等级回答信息从哪里来，内容性质回答它在说什么。一级材料不自动为真，二级材料不自动半真，三级材料也不自动为假。公司财报可同时包含已披露数字和管理层叙事；研报可同时引用历史事实、作预测并给判断。

四层信息的定义与交付规则见 [SKILL.md](../SKILL.md)。核验时分别标明事实、叙事、推断、判断：记录谁提出了主张、原文支持到哪一步；不因查到原文就将其解释或预测升级为事实。

## 2. 来源等级

| 等级 | 材料 | 采信边界 |
| --- | --- | --- |
| 一级 | 公司、交易所、监管与官方原始材料，如财报、公告、招股书、业绩会原文、官方统计 | 优先回查；区分审计、未经审计、预告和管理层说法，检查更正与重述 |
| 二级 | 券商研究、行业报告、数据库及专业机构研究 | 保留引用来源、样本、方法和估计属性，重要数字尽可能追至原始材料 |
| 三级 | 新闻、社媒、论坛及市场观点或访谈 | 用于发现线索、提出竞争解释；重要主张需要回到可核验原始证据 |

等级按材料实际出处与用途判断，不仅按载体判断；访谈中的当事人原话可证明其确有此表述，不独立证明其商业主张成立。多篇转载同一公告不算独立佐证。

数据商、Longbridge、Tushare等工具适合检索、汇总与计算，工具输出仍是待核验输入。搜索摘要、AI摘要和未打开的页面不能独立支撑“已核验事实”。

## 3. 按用途选来源

| 用途 | 优先来源与需保留的边界 |
| --- | --- |
| 财务、股本、重大合同、关联交易 | 正式披露原件及附注；区分审计状态、合并范围、更正和重述 |
| 客户、供应关系、产能、技术、认证 | 公告、客户/供应商交叉披露、认证原件；规划、认证、量产与收入分开 |
| 行业供需、份额 | 官方统计、协会或原始调查发布方；保留统计范围、样本与方法，机构估计仍为估计 |
| 股价、汇率等市场数据 | 交易所、央行或来源明确的数据商；标注时点、时区、币种、延迟、交易状态与复权方式 |
| 预测、一致预期 | 原始研究机构或口径明确的数据商；注明年度、更新时间、样本和统计方法，不与实绩混用 |

市场数据与预测仅在任务需要时取用，不因此扩展为估值或交易分析。重要商业说法尽可能用客户、供应商或其他独立原始材料交叉验证，不要求每个普通财报项目都有第二来源。

## 4. 关键证据记录

快速扫描：关键事实就近引用具体来源和时间，决定结论的数字提供可复查定位，不强制编号或台账。一般背景事实保留具体来源和时间即可。

深研：为关键主张分配E01、E02等编号，可复用证据，记录下列信息并随分析交付：

- **主张：** 准确限定的事实或数值、单位、币种、公司/分部及指标定义。
- **出处与定位：** 发布主体、文件标题、直达原文链接，关键表格的页码/表名或网页章节；用户本地材料用文件名及页码/章节。不能用搜索页或网站首页代替原文。PDF印刷页与阅读器页序不同则注明，图片表格核对原图。
- **时点：** 统计期间或数据时点、发布日期、实际获取日期。历史时点研究只用当时已公开信息，后续信息单列，避免前视偏差。
- **口径：** 合并/母公司、业务范围、单季/累计、审计状态及影响比较的汇率或复权属性。
- **核验状态与性质：** 原文已核对、二手待核、冲突或缺失；另标披露值、计算值、机构估计或预测等性质。

可压缩为“编号/主张｜原文与定位｜期间及口径｜核验状态”。“原文已核对”仅表示原文支持表述，不代表管理层判断已独立证实。匿名客户、未披露份额保持未知。

## 5. 数字与计算核验

1. 核对公司身份、证券代码、子公司与业务分部，防止同名或集团范围混淆。
2. 核对期间、单位、币种、定义与范围。区分归母、扣非、营业利润和EBITDA；区分订单存量、合同上限、交付和收入；累计数据不当单季，预测不当实绩。
3. 对决定结论的数字回看原表，检查单位换算、正负号和列对应。不同时间、范围与口径不能硬拼，不能对不可比指标强行横比。
4. 衍生值标“计算”，列公式、输入来源或证据编号、假设及舍入。累计值相减求单季前，确认合并范围及重述口径一致。毛利率变化用百分点，区分百分比。
5. 自由现金流、ROIC、维持性资本开支等非统一口径指标写清定义；维持与增长开支无法拆分时明确估计，或说明用总资本开支作为代理，不伪装为披露值。

## 6. 数字核验与因果核验分开

数字真实不代表因果成立。订单原文只能支持订单相关事实，不能单独证明利润或现金改善；后者还需要价格、成本、交付、收入确认、回款和资本占用的机制证据。

区分“公司有此披露”和“经营结果已经发生”，说明哪些关键箭头只是推断。证据同样支持其他解释时记录竞争解释，不能用资料数量替代因果检验。商业含义返回三问修正。

## 7. 时效、冲突与缺失

- 声称“最新”前检查更新报告、修订公告及后续披露。未找到更新不等于确认无更新；旧资料标历史期间，更正后采用适用版本并说明变化。
- 冲突先查时点、单位、范围、会计政策及数据商标准化调整。保留冲突值与出处，不取平均、不挑有利数字。关键冲突未解决时暂停该环节的确定性判断，列出补证路径。
- 付费墙、登录限制、链接失效或工具失败时注明未获取，寻找授权可用原件或官方镜像。不得声称读过未读材料，不靠模型记忆补数字、引文或链接。
- 仅分析用户材料时声明未外部核验，保留材料定位。可以继续条件式分析，不能把其中说法全部升级为已确认事实。

## 8. 交付前通过条件

关键事实可回查，关键数字口径一致，计算可复算，四层信息不混写。说明研究截止时间、重要缺口和未解决冲突；决定性证据不足时交付已验证部分，把结论降为“在条件满足时成立”或“尚待验证”，不下确定结论。

记录服务于本次分析；用户未要求时不额外保存或归档。教学材料与公开方法参考不能充当真实公司的当前证据。
