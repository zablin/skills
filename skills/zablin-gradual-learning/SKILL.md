# zablin-GradualLearning

## 总纲
学习闭环：**分析知识 → 诊断学况 → 制定材料 → 继承模型 → 验证模型 → 验证反馈 → 必要时重新拆分**

全课总纲采用「渐构靶图」：
- 上层：输入概念名、输出概念名、映射规律
- 下层：输入常量、输出常量、具体推测过程
- 核心模型：输入概念判别模型、输出概念判别模型、输入到输出联结模型
- 验证：必须用学习材料之外的未见情况测试泛化能力

## 强制原则
1. 课程定义优先，不用常规定义覆盖课程定义。
2. 先判断“根据什么，推测什么”。
3. 任何知识都按下上双层看：上层是概念/关系/规律；下层是具体对象/情境/现象/常量。
4. 上下层是相对关系：下层是当前实际问题，上层是当前用于理解问题的工具；不能机械固定成“下层=物质、上层=语言”。
5. 记忆=重现已见；学习=预测未见；标准学习=建构可泛化模型。
6. 禁止“顺序阅读，通篇记住”。
7. 听懂、认同、记住、会用分别判断；无未见情境证据时，不宣称用户已经学会。
8. 「语言视角」「复用视角」「系统视角」课程未展开，不补写；「抽编寻归」不纳入；「解释转移」无正式定义时仅标待补。

## 五组底层概念
### 具象层 / 抽象层
- 具象层：抽象之前，实际要处理对象所在的层。
- 抽象层：抽象之后得到的类别、概念、模型所在的层。

### 对象 / 内涵 / 概念 / 判别模型 / 外延
- 对象：实际要预测和处理的事物。
- 内涵：从已见对象中提取出的共有属性，用于判断通用处理规则适用于哪些未见对象；本质上是判别条件。
- 概念：抽象层面的代表/标签；根据内涵将对象划分为“此概念”和“非此概念”。
- 判别模型：若现象x满足A的共有属性，则归为A；否则归为非A。
- 外延：所有满足此抽象层面的对象整体。

### 抽象 / 判别 / 具象
- 抽象：从具体对象中提取共性，形成概念/模型。
- 判别：用概念内涵判断对象属于此概念还是非此概念。
- 具象：把抽象概念或模型落到具体对象、例子、情况。

### 已见 / 未见
- 已见：用于记忆重现。
- 未见：用于学习泛化验证。

### 一个 / 一类
- 一个：具体对象、具体情况、常量。
- 一类：概念、类别、普遍关系。

## 类别固有观
相信物质世界中存在对概念的先天固有划分，存在“唯一正确的先天固有本质”。课程强调从“客体层面的唯一答案”转向“主体可根据任务对现象进行不同编排”。

## 信息推测
- 输入：推测依据
- 输出：推测目标
- 输入空间：输入概念外延的组合
- 输出空间：输出概念的外延
- 映射关系：输入空间到输出空间的联结模型
- 适用范围：能被判别为该知识所依赖概念外延的现象范围
- 预测目标：最终要推测的对象或现象

标准分析顺序：推测任务 → 输入空间 → 输出空间 → 映射关系 → 适用范围 → 预测目标。

## 判别模型与联结模型
### 判别模型
回答：**“眼前这个情况，凭什么算这一类？”**

### 联结模型
回答：**“知道了这一类情况，在什么条件下能推出什么？”**

重要区分：归类正确≠关系一定成立；会背规律≠会识别适用场景；认出类别≠自动证明会推测。

一个实用知识最小拆分：
1. 输入概念判别模型
2. 输出概念判别模型
3. 输入→输出联结模型

## 上层材料 / 下层材料
- 下层材料：输入常量→输出常量；具体对象、情境、现象、变化与结果。
- 上层材料：输入空间→输出空间的映射规律；概念、关系、规律、模型描述。
- 学习材料（扁平、碎片化）≠知识（立体、结构化）。

## 自下学习 / 自上学习
### 自下学习
具体对象/下层材料 → 抽象 → 模型。
优点：有落地感、易理解。风险：建模方向多样、易偏离、易以偏概全、需反复试错。

### 自上学习
抽象描述/上层材料 → 渐构模型 → 指导下层。
前提：掌握基础概念、语法规则、表述转换能力、明确行为目标。
性质：认知适配、言不尽性、解释转移（待补）。

## 下上结合
- 例规法：例述→规述
- 规例法：规述→例述
- 真正学习：例→规→例→规→……

## 上层材料的语言学习
- 词络约束：多个句子中的已知词、语法和语境共同约束待学词，渐构其判别模型。
- 旧义重组：用已知概念及组织关系显性组合待学知识。
- 表述转换：把语言还原成概念和推测关系。
- 下上对齐：上层材料中每个概念，在下层材料中都应有对应的具体现象（常量）。

## 外显知识 / 内隐知识
### 外显知识
可用语言、文字、符号明确表述，可独立保存传递；可言传、可独立传递、主要可通过阅读/听讲/查阅获得。

### 内隐知识
能熟练运用但难完整表达；难以言传、实践习得、情境依附。

## 言不出 / 言不尽
- 言不出：知识存在，但缺少语言化所需支撑概念，无法完整表达。
- 言不尽：能表达，但语言只能覆盖知识部分侧面。

## 概念 / 表征 / 记忆
- 概念：突出“有别于其他类别”的属性。
- 表征：突出“被用于替代其他现象”的属性。
- 记忆：突出“被保存以便日后重现”的属性。

## 记忆编码
- 意识编码：认知阶段，属于外显记忆。
- 自主编码：感知/感觉阶段，属于内隐记忆。

## 学习材料分类
### 判别材料
- 判别上料：特征描述、特征对比、特征类比
- 判别下料：正例/负例、对比例组、外延对比（相等/包含/相交/互斥）

### 联结材料
- 联结上料：关系材料（关系类型/关系对比/关系类比）、因素材料（输入/输出/表征）、性质材料
- 联结下料：分段例组

## 学习闭环
### 1. 分析知识
阅读学习材料，找出所有待学知识，转换成判别模型和联结模型，再拆成输入概念判别模型、输出概念判别模型、输入→输出联结模型。

### 2. 诊断学况
检查：学习误区、学习偏好、坍缩误区、适配解释、既有知识正负迁移、适配拆分、掌握情况（泛化程度）。

### 3. 制定材料
材料来源：教师专家、书籍教材、验证实践、AI生成。
概念混淆→增加对比例组/外延对比/特征对比；上层丢失→提供验证材料并引导回上层。

### 4. 继承模型
用旧义重组、词络约束、表述转换、下上对齐等方式在脑中重建待学知识。

### 5. 验证模型
记忆验证重现已见情况；学习验证泛化未见情况。学习验证材料必须来自学习材料之外；同时检查是否出现上下层坍缩。

### 6. 验证反馈
失败则回到诊断学况，必要时重新拆分、更换材料、更换上下编排顺序，再验证。

## 渐构靶图
渐构靶图是全课总结。
- 上层：输入概念名、映射规律、输出概念名
- 下层：输入常量、输出常量、每组具体推测过程

使用原则：结构化组织；不顺序通篇记忆；保留下层输入细节；写出具体推测过程；用未见情况验证。

## 语言学习：单义判别
训练单词X某个具体义项a的内隐判别模型：
1. 选择义项a
2. 收集约3个表达a的不同例句
3. 归纳比较搭配、语境与共性
4. 用新例句验证是否能判别a

语言学习链：真实场景 → 条件反射/内隐模型（搭配习惯） → 外语表达 → 外显模型（语法规则） → 推测其它外语表达。

# 伴读 / 讲透文本（直接融入主 Skill）
当用户要求“伴读、陪我读、讲透、读这篇、分析一段文本”等，不另起体系，直接用渐构框架执行。

## 让事情可见
优先用原文例子；原文太抽象时补“教学设例”，但必须明确它不是原文事实。例子要有具体对象、条件、变化、结果。

## 让概念可辨
说明关键概念是什么、与相邻概念差在哪里；指出例子里哪些事实使它属于这一类；容易混淆时给近邻反例或边界例。不要只背定义，要建判别模型。

## 让关系可追
把前提→中间过程→结论展开，说明成立条件。区分定义、分类、相关、因果、类比、价值判断、行动主张；不要把所有箭头都当成因果。

## 让两层对得上
明确下层哪个对象/现象对应上层哪个概念、凭什么对应；若有预测，说明如何使用联结模型，以及输出在具体情境中意味着什么。

## 让边界改变判断
优先找条件变化、反例、边界情境、未决处，并判断是归类变化、关系失效，还是只收窄结论。原文无依据时保留未知，不替作者补机制。

## 让迁移可检查
给一个与已讲例子不同的新情境，让用户判断：是否适用、依据是什么、能推出什么。互动自测时先只给题，等用户回答后再反馈。

## 长文本
按完整语义单元组织，保留主线、重要分支和转折；不逐句平均用力，不切断承重论证。

## 英文材料
先给自然准确的中文译文，保留影响判断的关键英文短句/术语作校验锚点；仅在歧义、行话、文化典故影响理解时补充说明。

## 原文 / 推论 / 教学设例分开
必须区分原文明确陈述、解释者推论、补充教学设例。

## 不强制打印固定栏目
“下上结构”用于检查具体与抽象是否接通，不要求每段机械打印“下层/上层”。结构服务理解，不服务格式。

## 默认执行流程
1. 判断当前任务属于概念学习、实用知识、伴读还是验证。
2. 概念学习：内涵→正例/负例/边界例→判别模型→未见验证。
3. 实用知识：输入空间→输出空间→映射关系→适用范围→预测目标→三个模型。
4. 伴读：先明确作者在回答什么问题，再接通下层情境与上层概念/关系，检查边界并给迁移题。
5. 根据学习者知识结构选择自上/自下、例规/规例。
6. 组织最适材料，需要时用渐构靶图。
7. 最后用未见情况验证，而不是只让用户复述。

## 交付检查
1. 主要意思是否保留？
2. 关键概念能否在具体情境中辨认？
3. 判别依据是否清楚？
4. 联结关系条件是否清楚？
5. 下层与上层是否对齐？
6. 是否存在边界条件/反例会改变判断？
7. 是否区分原文、推论、教学设例？
8. 是否避免把听懂/认同/记住误判成会用？
9. 是否提供未见情境迁移检查？
10. 是否避免无依据宣称用户已学会？

## 输出风格
优先：连贯段落、必要小标题、简短公式、上下层对照、输入→映射→输出、正例/负例/边界例、未见验证题。
避免：百科式堆砌、只给定义不建模型、只给理论不给下层、只给案例不抽规律、机械套栏目、用课程外术语替换课程术语。
