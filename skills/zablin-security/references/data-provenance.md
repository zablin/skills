# 数据来源与溯源规则

目标是让读者能够重查关键事实、复算关键数字，并分清披露、推断与预测。来源真实不等于内容必然正确；规则约束每次取证过程，不承诺外部数据绝对准确。

## 1. 按用途选择来源

| 数据用途 | 首选来源 | 需要保留的边界 |
| --- | --- | --- |
| 财务、股本、重大合同、关联交易 | 交易所/监管披露原件、公司正式财报及附注 | 区分审计报告、未经审计中报/季报、业绩快报和预告；检查更正与重述 |
| 客户关系、产能、技术、认证 | 正式公告、客户或供应商披露、监管认证文件 | 管理层说法标为“公司披露/声称”；规划、认证、量产和收入贡献分开 |
| 行业供需、市场份额 | 官方统计、行业协会、原始调查或研究发布方 | 保留统计范围、样本和方法；机构估计不写成确定事实 |
| 股价、成交、汇率 | 交易所、央行或有来源说明的数据商 | 标注时间、时区、币种、交易状态、延迟和复权方式 |
| 分析师预测、一致预期 | 原始研究机构或提供覆盖与统计口径的数据商 | 标注预测年度、更新时间、样本及统计方法，不与已实现业绩混用 |

数据商、Longbridge、Tushare 等工具适合检索、汇总和计算，但不因工具名称可信就自动视为原始证据。决定三问结论的财务数字优先回查披露原件；市场报价无法逐笔回查时，明确供应商与时间属性。新闻、研报、社交媒体和搜索摘要用于发现线索；搜索摘要、AI 摘要及未打开的页面不能独立支撑已核验事实。

## 2. 建立可复查证据记录

为决定结论的事实、数字与计算分配 E01、E02 等编号。同一证据可复用。记录：

- **主张**：数值或准确限定的事实，单位、币种、公司/分部及指标定义。
- **出处**：发布主体、文件标题、直达原文链接；本地材料用文件路径。不要以搜索结果页或网站首页代替具体文件。
- **定位**：PDF 页码与表名、网页章节或表格行；PDF 印刷页码与阅读器页序不同时注明。图片表格需检查原图，不能只依赖可能错位的文本提取。
- **时点**：统计期间/数据时点、发布日期、实际获取日期。历史时点研究只使用当时已公开信息，后续信息单列，避免前视偏差。
- **口径**：合并或母公司、业务范围、单季或累计、审计状态、复权/汇率等影响比较的属性。
- **核验状态**：原文已核对、二手待核、存在冲突或缺失；注明披露/机构估计/管理层预测等性质。

交付可压缩为：

| 编号/主张 | 原文与定位 | 期间及口径 | 核验状态 |
| --- | --- | --- | --- |
| E01：关键事实或数值 | 发布者、文件直链、页码/表名 | 期间、单位、范围；发布及获取日期 | 原文已核对/二手待核/冲突/缺失 |

“原文已核对”仅表示原文确实支持这一表述，不代表已独立证实管理层判断。对匿名客户和未披露份额不得自行补全。

## 3. 数字和因果分别核验

1. 核对公司身份、证券代码及业务分部，防止同名公司或集团/子公司混淆。
2. 核对期间、单位、币种、会计口径与指标定义。区分归母净利润、扣非归母净利润、营业利润、EBITDA；区分订单存量、合同上限、实际交付和确认收入。
3. 对决定结论的数字回看原表，检查单位转换、正负号和列对应；对关键预测或商业说法，尽可能找客户、供应商或其他独立原始证据验证。多篇转载同一公告不算独立佐证，不强求每个普通财报项目都有第二来源。
4. 衍生数值标为“计算”，写公式、引用输入证据编号，说明舍入及假设。累计值相减得到单季值时，先确认范围及重述口径可比。毛利率变化用百分点；不能将百分点与百分比混用。
5. 自由现金流、维持性资本开支、ROIC 等非统一口径指标须给定义；无法区分维持与增长开支时明确估计或使用总资本开支作代理，不伪装为披露值。无法对齐口径时不强行横比。
6. 数字真实不能单独证明因果。把“公告确有订单”与“该订单会提升利润”分开；后者需要价格、成本、交付和回款机制的证据。

## 4. 时效、冲突和无法访问

- 声称“最新”前检查是否有更新报告、修订公告或后续披露。旧资料仍可用，但标注历史期间；未找到更新不等于确认没有更新。
- 原始披露更正后，采用适用的更正/重述版本并说明变化；审计与非审计、历史与预测、不同统计范围分别展示。
- 出现差异先检查时点、单位、范围、会计政策及数据商标准化调整。保留冲突值与来源，不取平均、不挑选有利数字；关键冲突未解决时暂停该环节的确定性判断，列出补证路径。
- 遇到付费墙、登录限制、失效链接或工具失败，注明未获取，寻找授权可用的官方镜像/原件。不得声称读过未读原文，不用模型记忆补出数字或链接。
- 用户材料模式说明未做外部核验，保留文件和页码定位；可以继续条件式分析，但不能把材料中说法统一升级为已确认事实。

## 5. 发布前通过条件

关键数字均有原文定位或明确的待核状态；计算可复算；每条主要因果判断能追溯到证据；预测与实绩分开；结论披露截止时间、最重要缺口和冲突。任一决定性证据缺失时，交付已验证部分及补证清单，将整体结论写为条件成立或尚待验证。

来源台账随本次分析交付；用户未要求保存文件时不额外归档。公开方法参考链接仅用于说明分析设计，不能充当公司数据证据。
