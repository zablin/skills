# 三问主线 · 六问验证

将产业机会追踪到具体公司的收入、利润和现金。三问组织推理，六问提供证据，最后检验链条是否成立。默认用简体中文输出。

核心命题：什么稀缺，价值如何到达这家公司，公司凭什么持续留下利润和现金？

三问是研究与成稿的主框架。先提出三问的待检验假设，再按需调用六问取证，回到三问修正结论。六问是辅助工具，不要求先填完整问卷才开始分析。产业研究尚未选定公司时，六问先作用于代表性商业模式，不能把环节优势自动归给所有公司。

## 确定对象

明确公司或产业环节、业务范围、研究时点和判断期限。多业务公司按相关分部分析，不能用集团收入证明某项业务受益。用户未给对象时询问对象；其他缺失信息能合理设定的，说明假设后继续。

## 副框架：六问提供公司证据

1. **客户是谁？** 谁使用、谁付钱、解决什么痛点？需求来自真实使用还是备货？客户集中度和支付能力如何？
2. **卖什么？** 交付的产品、服务或能力是什么？位于哪个产业环节？收入与交付如何确认？
3. **如何收费？** 一次性、订阅、按量、分成还是长期合同？谁定价、何时调价、何时收款？
4. **成本在哪里？** 主要变动成本、固定成本、研发、折旧、获客及资金占用是什么？利用率与规模如何影响利润？
5. **为什么不被替代？** 客户获得什么独特价值？竞争对手为何难复制？切换成本、认证、资源、技术或运营优势如何失效？
6. **什么会让判断反转？** 哪些需求、供给、价格、技术、客户或政策变化会打断受益链？怎样观察？

底稿服务于推理，不必在成稿中重复展示。证据不足写“未知”及需补证据，不以印象补齐答案，不默认进行机械打分。

## 主框架：三问形成因果链

### 一问：稀缺性——机会从哪里来？

识别需求增长的来源、有效供给、真正瓶颈、供给响应速度及稀缺窗口。区分产业环节稀缺与目标公司实际拥有稀缺能力。技术难、市场大或需求快都不能单独证明稀缺，更不能单独证明公司获利。

主要调用六问中的客户、产品、替代证据，并用反转问题检验扩产、替代路线和需求变化。

把瓶颈具体到产品规格、认证、交付能力或资源约束，核查现有供给、可替代供给与新增有效供给。宣布扩产不等于可交付产能，技术难度不等于商业稀缺。说明需求是否必须经过这一环，以及目标公司实际能交付多少、是否已获客户认可。

本问收口：〔需求〕受〔有效供给瓶颈〕约束，〔公司能力〕是否占据瓶颈，稀缺可能持续到〔事件或时间窗口〕；最大反证为〔替代或供给变化〕。

### 二问：价值传导——机会如何到达公司？

写出可检查的路径：需求变化 → 采购与订单 → 交付/验收 → 收入的量、价、结构变化。追踪议价权、成本转嫁、合同期限和收款节奏，定位谁付费、谁受益、谁承担成本。

主要调用客户、产品、收费、成本证据。区分订单与收入、行业增长与份额增长、真实需求与补库存。每个关键箭头说明机制、证据、滞后及可能断点，避免“行业景气所以公司受益”的跳步。

检验利润池归属：哪个环节掌握客户、标准、渠道或关键资源，谁能涨价、谁承担资本开支和履约风险，上下游是否会挤压目标公司的收益。供应关系需核验，不能把“A供应B、B供应C”当作“A已受益于C”的事实；还需验证产品匹配、采购份额、实际交付及业务重要性。

本问收口：〔需求变化〕通过〔客户采购与合同机制〕影响〔销量/价格/结构〕，收益由〔参与者〕分配；到达目标公司的关键条件是〔条件〕，最可能断在〔环节〕。

### 三问：价值捕获——公司能留下多少？

验证收入增长能否转为毛利、经营利润、经营现金流，以及扣除必要资本开支后的现金；结合营运资金、债务与再投资需求判断持续性。按业务选取关键指标，不将利润与现金流误写成严格串行的会计恒等式，不将自由现金流等同于可分红利润。

主要调用收费、成本、替代证据。说明利润留在公司的机制、竞争如何侵蚀它，以及维持优势需要付出什么代价。重资产业务关注利用率、折旧、资本开支与回收期；平台或订阅业务按需关注留存、付费转化、单位交付成本和获客回收期。

每项关键优势都落到可观察的财务或经营结果：定价权对应售价与毛利表现，切换成本对应留存和复购，规模优势对应单位成本，稀缺能力对应有效订单、份额或资本回报。结果未兑现时，区分合理滞后、商业化尚未验证与优势不存在，并给出后续检验条件。

用最强的竞争解释检验持续性：对手是否能正面复制，客户是否会自研或增加供应商，新技术、标准化、开源或不同收费方式能否绕开这一环？选择与对象相关的路径，说明发生条件及对利润池的影响，不机械穷举。

结合管理层资本配置、治理和融资约束，检验经营收益能否留给股东；重点核查持续稀释、关联交易、低回报扩张和再融资依赖等有证据的影响，不另行扩展成无关清单。

本问收口：〔收益〕在扣除〔成本、营运资金及必要再投资〕后，能否形成〔利润与现金结果〕，凭〔持续机制〕保留多久；〔竞争绕过或资本配置变化〕会使其失效。

六问与三问是多对多关系，不强行逐项配对。第六问检验整条链：任一关键环节缺少证据，最终判断必须保留该条件。

## 证据与核验

涉及真实公司的事实或数字时，先阅读并执行 [数据来源与溯源规则](references/data-provenance.md)。本 skill 不自带数据源，也不默认信任任何 API、数据库或其他 skill 的结果；工具输出是待核验输入。

- 分开呈现事实、推断和判断。事实附来源、日期、统计期间、口径与范围；推断解释中间机制及关键替代解释；判断附条件、期限和置信度依据。
- 对真实公司的当前研究，使用可用检索或数据工具核验，优先公告、财报、监管文件及客户/供应商披露，提供可访问的原始来源链接。不同口径或时期不可直接拼接。
- 只分析用户材料时，说明材料边界，不声称已外部核实。无法获取的数据列为缺口，不编造数字、引文或链接。
- 教学材料提供分析方法，案例中的历史数字、预测、比喻和绝对化说法不能作为普遍规律或当前事实。行业受益与股票是否值得买分开判断；没有估值分析时不推出买卖结论。

## 默认交付

优先输出一页纸密度的分析；用户要求深研时再展开。内容包括：

1. **对象与待检验判断**：业务、产业位置、时点、期限，以及本次真正要检验的命题。
2. **三问主体**：每问给出结论、关键证据、传导机制及最重要的缺口；自然嵌入六问答案。
3. **条件式结论**：“在〔条件〕下，〔瓶颈〕经由〔路径〕，使〔公司/业务〕在〔期限〕内可能获得〔收入/利润/现金结果〕；目前最薄弱的证据是〔缺口〕。”
4. **反转与补证**：选取最关键的可观察信号，说明它打断哪一环、观察来源与频率；阈值需有依据，否则说明变化方向及待确认标准。列出优先补充的证据和来源。

关键事实与数字就近引用证据编号和链接，附精简证据台账，记录来源定位、期间口径及核验状态。篇幅限制不能省略决定结论的证据。明确研究截止时间与尚未核验的数据；缺乏可靠证据的关键环节不得输出为已确认。

结论可以是“链条尚未成立”。不要为得到确定答案掩盖断点，也不要把十八个交叉格子或九个独立答案当作完成分析。

交付前检查：是否把行业瓶颈误当公司壁垒？是否把订单误当收入、利润误当现金？最强反方解释是否仍能解释相同事实？每个反转信号是否指向具体假设？最后明确链条已验证的部分、尚待验证的部分和决定结论的最薄弱环节。

## 方法参考与取舍

以下公开 skill 用于设计参考，不是公司事实来源或运行依赖。需要理解方法来源或继续改进本 skill 时再阅读，不要求每次研究加载。

- [company-investment-research](https://github.com/bingofreedom/company-investment-research-skill)：参考资源能力到客户价值、定价与财务兑现的因果链，以及利润池、竞争绕过与证伪分析；保留三问作为主结构，不引入完整模块体系。
- [serenity-analyst](https://github.com/videGavin/serenity-analyst)：参考供应集中、有效扩产、客户认证与瓶颈收入重要性的检验；不沿用个人交易风格、仓位规则、情绪判断或统一排斥某种估值方法。
- [buffett-investment-research](https://github.com/MichaelRochonnn/buffett-investment-research)：参考现金转化、维持性资本开支、资本配置及财务韧性；不将特定投资风格的偏好作为所有企业的淘汰条件。

这些参考用于强化验证，不能替代用户的三问六问框架；不依赖特定付费数据工具或作者个人环境路径。
