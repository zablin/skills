# 现代视角

用于经典论文、历史影响较大的论文，或用户明确要求“今天怎么看”的情况。

目标不是给老论文打分，而是区分：

- 哪些核心洞见仍然成立
- 哪些属于历史条件
- 哪些后来被修正
- 哪些被后世误读、高估或低估

## 1. 哪些仍然成立

可以重点看：

- 问题重构方式
- 机制
- 判断框架
- 实验思想
- 测量思想
- 可迁移原则

不要因为具体技术细节过时，就否定其概念价值。

## 2. 哪些已经变化

寻找：

- 技术限制
- 规模假设
- 评测方法
- 实现路径
- 具体预测
- 后来被缩小适用范围的判断

## 3. 后世高估或误读了什么

问：

- 是否把复杂主张压缩成一句口号
- 是否给作者加上了原文没有的主张
- 是否把思想实验当成完整定义
- 是否忽略了证据边界
- 是否把历史影响力误写成科学证明

## 4. 后世低估了什么

问：

- 哪些不那么出名的部分后来反而更持久
- 哪些思想比论文最著名的标签更有迁移价值
- 哪些判断后来被事实证明更有前瞻性

## 5. 反事实

谨慎追问：

- 如果没有这篇论文，哪些思想可能仍然会被别人独立发现？
- 哪个贡献真正改变了研究路径、问题语言或思考方式？
- 哪部分只是“最早提出”，哪部分真的很难替代？

反事实属于分析判断，不是历史事实。

## 6. 分离规则

始终区分：

- 原论文当时说了什么
- 后来的证据证明了什么
- 今天的人如何重新解释它

不能把现代解释倒写进原作者嘴里。
