# 论文类型

论文形态和贡献类型是两个不同维度。

## 1. 论文形态

常见形态包括：

- **理论型**：建立形式关系、证明、概念结构或解释理论
- **实验型**：通过控制实验或比较实验验证假设或干预
- **方法型**：提出新的过程、算法、干预或工作流
- **系统型**：构建完整能力、架构或运行系统
- **观察型**：研究自然发生的模式或关系，不进行控制干预
- **综述型**：整合既有研究，而不是主要生成新的直接证据
- **混合型**：同时结合多种研究形态

一篇论文可以有一个主形态，也可以有多个次形态。

## 2. 贡献类型

### 方法 / 干预

重点问：

- 改了哪个动作？
- 哪些步骤变了？
- 输入经过什么变化？
- 为什么结果可能不同？
- 在什么条件下改进会消失？

### 解释 / 理论

重点问：

- 哪些因素在起作用？
- 它们怎么关联？
- 哪些发现能被这条关系解释？
- 哪些发现仍然解释不了？
- 什么条件下会失效？

### 测量 / 评测

重点问：

- 旧指标漏掉了什么？
- 新评测真正区分了什么？
- 哪些差异是直接测到的？
- 哪些因果解释仍然没有被证明？

测量到差异，不等于解释了为什么有差异。

### 资源 / 系统

重点问：

- 提供了什么新数据、新能力、新基础设施或新规模？
- 降低了哪个瓶颈？
- 贡献主要体现在成本、速度、可用性、规模、可靠性还是覆盖面？
- 还受哪些限制？

## 3. 混合贡献

对于混合型论文：

- 选一个主要贡献类型
- 保留论文真正必要的独立研究主线
- 不要为了简化而把不同贡献线强行压成一条

## 4. 各类型常见误读

- 理论论文不一定有控制实验
- 观察关系不自动等于因果机制
- 测量论文可能发现差异，但并没有解释原因
- 系统性能提升不等于所有部署场景都更优
- 资源论文可以很重要，即使没有统一机制
- 综述论文不能写成“这些结果都是它自己做出来的”
