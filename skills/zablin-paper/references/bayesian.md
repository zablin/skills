# 贝叶斯视角

## 核心定义

**抽象描述：根据新获得的信息，更新对未知事件可能性的判断。**

一句话记忆：

> 贝叶斯定理 = 用新证据修正原来的判断。

只有当论文存在下面这个结构时才使用：

原有判断
→ 获得新证据
→ 判断证据更支持哪种可能
→ 重新分配概率
→ 得到更新后的判断

如果没有这个结构，就跳过。

## 1. 输入变量或空间（推测依据）

### 原有判断

在获得新信息之前，对目标事件可能性的判断。

也就是先验概率。

### 新信息

实际观察到的证据。

### 证据可靠性

判断：

- 如果目标事件发生，这个证据有多大概率出现
- 如果目标事件不发生，这个证据又有多大概率出现

可以概括为：

**原有判断 + 新证据 + 证据的可靠程度**

## 2. 输出变量或空间（推测目标）

获得新证据之后：

> 目标事件现在有多大概率成立？

也就是更新后的判断，即后验概率。

## 3. 映射关系

使用：

**原有判断 → 获得新证据 → 判断该证据更支持哪种可能 → 重新分配概率 → 得到更新后的判断**

## 4. 用于论文分析时

问：

- 在看到新证据前，一个合理读者原来会怎么判断？
- 论文新增了什么证据？
- 这个证据有多可靠、有多能区分不同可能？
- 它更支持哪种可能？
- 原判断应该怎样修正？
- 更新以后还剩哪些不确定性？

## 5. 使用约束

- 论文没有足够概率信息时，不伪造具体数字
- 可以做定性更新，但必须明确是定性判断
- 不要把贝叶斯当作高级术语装饰
- 更新后的判断仍然必须保留论文原有条件和证据边界
