# Article Archetypes：文章原型

## 现象解读型
观察到什么
→ 为什么奇怪
→ 常见解释
→ 哪里不够
→ 更好的关系
→ 对读者意味着什么

## 方法论型
具体任务
→ 旧做法卡住
→ 新方法介入
→ 方法如何工作
→ 第二场景迁移
→ 适用边界

## 产品体验型
真实需求
→ 为什么尝试
→ 实际操作
→ 出乎意料的地方
→ 适合什么
→ 不适合什么

必须区分个人体验与普遍结论。

## 调查实验型
问题
→ 实验设计
→ 第一次结果
→ 新问题
→ 第二轮检查
→ 最终判断

不要把一次测试写成普遍规律。

## 研究转译型
研究在问什么
→ 旧认识哪里不够
→ 作者做了什么
→ 关键证据
→ 结果如何改变判断
→ 对现实有什么边界内的意义

## 观点评论型
明确判断
→ 为什么很多人会得出另一种判断
→ 冲突来自哪里
→ 证据与机制
→ 反方最强论点
→ 边界
→ 回到判断

## 经验复盘型
原目标
→ 当时怎么做
→ 哪里出问题
→ 真正原因
→ 后来怎么改
→ 哪些经验可迁移
→ 哪些只属于当前情境
