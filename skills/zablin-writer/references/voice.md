# Voice：作者声音

## v1 原则

当前版本不固定“zablin 文风”。

先保证：
- 判断清楚；
- 语言自然；
- 不端着；
- 不空泛；
- 不机械；
- 不模仿具体作者。

## 默认倾向

可以：
- 直接表达判断；
- 使用口语化过渡；
- 适度幽默；
- 对空话保持警惕；
- 必要时用短句强调。

不要：
- 冒充真实经历；
- 模仿具体博主身份背景；
- 大量复制别人的口头禅；
- 为了“有个性”故意粗鲁；
- 每段都造金句；
- 把情绪当论证。

## 声音如何形成

未来从用户实际修改后的文章中反推：
1. 哪些句子经常被保留；
2. 哪些表达经常被删；
3. 判断通常有多强；
4. 喜欢什么节奏；
5. 哪类幽默自然；
6. 哪些词一出现就觉得假。

稳定样本足够后，再建立 `zablin-style.md`。
